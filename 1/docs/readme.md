# Вариант № 10: «Объект XML»
## Реализовать набор функций для преобразования структуры записи в толковом словаре в
строку формата xml и обратно.
Структура записи в толковом словаре состоит из следующих полей:
• слово (word, строка длиной до 20 символов);
• толкование (meaning, строка произвольной длины);
• ударение (emphasis, целочисленное значение, соответствующее номеру ударной гласной в
слове).
На вход функции передаётся экземпляр структуры и название записи. Функция
преобразования в строку должна вернуть строку в формате xml.
Функция преобразования из строки должна получать на вход строковое представление
экземпляра и возвращать исходный экземпляр структуры. Экранирование символов
допускается не реализовывать.
Например, запись {word=“apple”, meaning=“round fruit”, emphasis=1} при названии «record»
необходимо преобразовать в строку (пробельные символы и переносы строки, кроме
заключённых в кавычки, служат исключительно для форматирования и могут быть
опущены):
### <record>
### <word>apple</word>
### <meaning>round fruit</meaning>
### <emphasis>1</emphasis>
### </record>

## Реализовать 3 перегрузки описанных функций:
1. Работает с нуль-терминированной строкой (const char*).
2. Работает с массивом символов и их количеством (const char* + size_t).
3. Работает с экземпляром класса std::string.
* Тип возвращаемого из каждой перегрузки значения должен совпадать по стилю с типом
передаваемого.Для всех типов объявить using через класс со статическим членом.Если передаётся тип данных из языка C++ (string, vector, …), то и возвращать
необходимо тип из C++. Если передаётся сырой тип из C (char*, int*, …), то вернуть также
нужно тип из C.
